# VentSpace Landing Page

Static landing page for the VentSpace MVP.

## Run locally

Open `index.html` directly in a browser, or use any static server.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Other**.
4. Build command: leave blank.
5. Output directory: leave blank.
6. Deploy.

## Important

The waitlist form currently demonstrates the UI only and logs submissions to the browser console.
Before launch, connect the form to a real endpoint (for example, Formspree, a serverless function, or your future Django API).
